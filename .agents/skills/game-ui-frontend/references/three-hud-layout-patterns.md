# 3D HUD patterns

Apply the skill's shared playfield budget and project platform scope. Keep center/lower-middle clear, secondary information initially closed.

| Pattern | Use |
| --- | --- |
| Objective chip | Short edge-aligned goal, optional location/mode line |
| Interaction prompt | Temporary lower-edge pill near interactables/onboarding; dismiss/fade after use |
| Status strip | Compact health/energy/party labels/icons/meters |
| Drawer/journal | Map, notes, long controls, multistep goals; deliberately opened |
| Pause/settings modal | Explicit state with camera drag/look and pointer lock gated |

Example: objective top-left, small status top-right, transient prompt below; map/inventory/settings in drawer. Mobile may need fewer persistent elements. Avoid four-to-six panels, giant titles, permanent control lists and dashboard layouts.

Prompt addition: “Leave most of the scene available for movement/spatial reading; use one compact objective/status surface and transient hints.”
